# Γραμματοσειρές

Δύο οικογένειες, και οι δύο με **ελληνικά και γαλλικά** — απαραίτητο, γιατί οι
δύο σελίδες κάθε σκηνής πρέπει να έχουν ταυτόσημη διάταξη.

- **Alegreya Sans** — το σώμα του διαλόγου. Ζεστή ανθρωπιστική γραμμή, πολύ πιο
  φιλική από τη Georgia που είχε πριν, και διαβάζεται άνετα σε 18–20 στιγμές.
- **Comfortaa Bold** — τίτλοι και σήματα. Στρογγυλή και παιχνιδιάρικη· μόνο για
  λίγες λέξεις, ποτέ για τρεχούμενο κείμενο.

Και οι δύο από το `google/fonts`, άδεια OFL. Είναι δεσμευμένες στο repo ώστε το
`make cartes` να μη χρειάζεται δίκτυο. Δοκιμάστηκαν και απορρίφθηκαν: **Nunito**
και **Mulish** (δεν έχουν ελληνικά), **Onest** (το ίδιο).
