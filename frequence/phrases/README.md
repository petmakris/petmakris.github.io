# Common French phrases — study deck

A companion to the frequency-word sheets one level up. Compact, colour-coded
A4 sheets of common, useful French phrases with English translations, meant to
be printed and studied. Same visual language as the word sheets (theme colours,
striped sections), but the rows are whole phrases rather than single words.

Unlike the words, phrases have **no frequency corpus** — they are **curated**
(generated by LLM passes, deduped, grouped by theme), most-useful first.

## Quick start

```
make                 # show targets (default)
make all             # -> out/phrases_all.pdf   (every sheet, one printable PDF)
make build BAND=2    # -> out/phrases_sheet_02.pdf  (a single sheet)
make clean           # remove generated PDFs
```

Or directly: `python3 build_phrases.py --all` / `python3 build_phrases.py --band N`.

## Layout

- Two columns, single-line entries: French phrase (bold, **theme-coloured**) +
  English gloss (grey), with the gloss auto-shrinking to fit long phrases.
- Striped sections of 10 rows for visual targeting.
- A centred legend + `feuille N/M` pill on top of each sheet's first page.
- One sheet = up to two A4 pages; at the current density ~244 phrases per sheet.

## Data

`data/phrases.tsv` — one phrase per line, tab-separated:

```
french <TAB> english <TAB> theme
```

`theme` is one of: `salutations questions quotidien opinions connecteurs expressions`
(the legend colours). Phrases are ordered essentials-first, then grouped by theme.
`build_phrases.py` slices this master list into sheets by layout capacity, so the
sheet count follows the data size automatically.

## Themes (legend)

| Theme        | Colour | Covers                                   |
|--------------|--------|------------------------------------------|
| salutations  | blue   | greetings, goodbyes, politeness          |
| questions    | amber  | question patterns                        |
| quotidien    | green  | everyday / survival (travel, food, …)    |
| opinions     | rose   | feelings, opinions, agreement            |
| connecteurs  | grey   | connectors & discourse markers           |
| expressions  | purple | set expressions & idioms                 |

## Adding more phrases

Append more `french<TAB>english<TAB>theme` lines to `data/phrases.tsv` (keep the
theme tags valid) and re-run `make all`. New sheets are created automatically as
the list grows. Phrases were generated by domain-specialised LLM passes (one per
topic) then deduped accent/punctuation-insensitively; repeat that approach to
extend the deck.

## Known caveats

- Curated, not frequency-ranked — later sheets trend toward slightly less common
  phrases (idioms, deeper connectors). Edit `data/phrases.tsv` to taste.
- Very long phrases have their English gloss shrunk (and, rarely, truncated) to
  stay on one line.
